# Plot coefficients from simple slopes analysis

This creates a coefficient plot to visually summarize the results of
simple slopes analysis.

## Usage

``` r
# S3 method for class 'sim_margins'
plot(x, ...)
```

## Arguments

- x:

  A
  [`sim_margins()`](https://interactions.jacob-long.com/reference/sim_margins.md)
  object.

- ...:

  arguments passed to
  [`jtools::plot_coefs()`](https://jtools.jacob-long.com/reference/plot_summs.html)
